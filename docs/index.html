Chris Neale PhD Project

# whoami

I'm Chris, a PhD student studying Digital Forensics at the Open University. I am interested in how digital artefacts can be manipulated by suspects to try and hide their actions and mislead investigators. My project is primarily focussed on understanding the ways in which such tampering activity can be detected. This broadly fits under the theme of what I have termed 'Zero Trust Digital Forensics'. In the first published paper on this, I defined this concept as 'A strategy adopted by investigators whereby each aspect of an investigation is assumed to be unreliable until verified'.

Take a look at the Published Work section which has more details about the research papers published on this subject.

On this site, I'll capture various aspects of my project as it develops. If you have any questions about the research, please feel free to get in touch via email.

All of the code / research data generated as part of this project will feature on my GitHub.
